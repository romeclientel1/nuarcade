# Vespara 6.0.5 Showcase Capture Plan

## Purpose

Capture a polished approximately 75-second introduction to Vespara: a living, controller-first world for entering, exploring, and launching a game collection. Record from the packaged Windows application at 1920×1080 where available, at 60 fps, with the application window cropped cleanly and no desktop clutter.

Use controller input when possible. Let native fades, the Attract cinematic dip, Sanctuary shimmer, and focus movement play at their natural speed. The sequence should feel calm and observed rather than like a rapid feature montage.

## Edit variants

### A. 60-second social cut

Use 0:00–0:06 Attract, 0:06–0:14 Sanctuary entry, 0:14–0:22 Recently Played, 0:22–0:31 Library, 0:31–0:38 return, 0:38–0:47 Control Room, 0:47–0:54 Traveler Gate, and 0:54–1:00 closing/end card. Keep one complete cinematic dip and one complete return handoff; remove the second return if timing becomes crowded. Do not speed-ramp footage or shorten native fades.

### B. 75–90-second GitHub/project cut

Use the full shot list above and optionally extend Attract opening, Library browsing, and the Control Room station impression by 5–15 seconds total. Add a reduced-motion comparison only as a separate appendix clip, not inside the main story. Keep the final end card on screen for at least 5 seconds.

## Pre-recording checklist

- Build and launch the fresh packaged `NuArcade.exe` from the validated release build.
- Set capture output to 1920×1080 and 60 fps where possible; verify the application is the only visible window.
- Disable Windows notifications, overlays, chat popups, and unrelated background windows.
- Use a controller with a charged battery; keep keyboard input available as a fallback.
- Confirm English copy for the main take; record Spanish as an optional second take if desired.
- Confirm reduced motion is off for the primary atmospheric take.
- Ensure a neutral traveler and non-sensitive game/library state are selected.
- Check that no private paths, usernames, account identifiers, or desktop files can appear.
- Confirm the recording soundtrack is original, licensed, or use the silent/no-music mix.
- Prepare a clean end-card title and the release URL before editing.

## Privacy and publication checklist

- Do not show game-path fields, emulator install paths, usernames, profile names, or local drive labels.
- Avoid commercial game footage, box art, or music unless publication rights are clear.
- Prefer Vespara’s original Sanctuary, Attract, Library chrome, and Control Room presentation.
- Crop the application directly; do not include the taskbar, desktop, notifications, or other applications.
- Review every frame around focus changes and overlays for accidental private text.
- Publish the installer link and checksum only through the official repository release.

## Post-recording review checklist

- Attract scene images remain stationary while atmosphere moves subtly.
- The cinematic dip never shows two scene plates at once.
- Sanctuary shimmer stays in the distant horizon/sky region and never washes UI.
- Library and Control Room entry/return fades are complete, calm, and non-overlapping.
- Focus rings move predictably; no stale or hidden control receives focus.
- Traveler Gate reads clearly and does not expose private profile information.
- No white, pure-black, rectangular, clipping, or one-frame flash appears.
- Audio is continuous and publishable, or the silent mix is clean.
- Captions remain readable at 1920×1080 and are not baked over important UI.
- The final title, release number, and GitHub call to action are accurate.
