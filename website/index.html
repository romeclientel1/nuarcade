Before you arrive

Traveler Recognition

Every session opens the same way: Vespara asks who's stepping up to the cabinet before anything else happens.

  • Existing Travelers. Pick a Traveler you've used before and pick up exactly where you left off.
  • Create a new Traveler. Start a fresh profile of your own, separate from anyone else's.
  • Continue as Guest. Play without creating a profile at all.
  • Everything stays personal. Each Traveler keeps their own favorites, playtime, and recently played history.
  • Guest sessions aren't saved. A Guest's activity isn't written to any Traveler's profile.

Where your collection lives

The Library

Games are organized by system, shown as category tabs — only systems that actually have games in them appear.

Finding a game

  • System-based browsing. Move between systems without losing your place.
  • Search and sorting. Find a game by name, or reorder by most played, most launched, recently added, top rated, or system.

Making it yours

  • Favorites. Mark games for quick access.
  • Collections. Group games into your own custom lists.
  • Custom system logos. Replace any category's plain text with your own logo artwork.

Inside a game's Archive View

  • Archive View. Selecting a game opens its detail view — artwork, a gameplay preview video where available, and launch options.
  • Artwork and video previews. A background gameplay video plays behind the selected game where one is available.
  • AI Game Coach. Move lists, tips, strategies, and natural-language search for the selected game — no API key required.

Configuration, shaped like a place

The Control Room & Media Wing

Reached from the Sanctuary, the Control Room holds all of Vespara's configuration in two wings — one for the systems that make your games playable, one for the artwork and video that make your collection feel alive.

Systems Wing

Makes the worlds playable.

  • Emulators. Detected emulators and their install paths.
  • Game Paths. The folders Vespara scans for each system.
  • Controllers. Test connected gamepads.
  • Launch Behavior. Attract mode, idle timing, auto-launch behavior.
  • Display & Performance. Fullscreen, CRT scanline effect, theme.
  • Preferences. Language, audio, and about/version info.
  • Systems Archive. Rescan, cache, and library maintenance tools.

Media Wing

Makes the collection come alive.

  • Artwork. Box art and marquee management, including automatic SteamGridDB fetching with your own API key.
  • Videos. Per-game and bulk gameplay video fetching, including direct YouTube fetching.
  • Scraping. Import media from your own EmuMovies account and Sync app.
  • Custom system logos. Replace any Library category's plain text with your own logo artwork.
  • Bezels. Fetch bezel artwork by system.
  • Media Restoration. Backup, restore, and orphaned-media cleanup.

Opening any Media Wing station takes you into a screen still titled Media Manager — that's the actual screen behind every Media Wing station, not a separate or disconnected module. Vespara does not distribute copyrighted artwork, ROMs, BIOS files, or emulator software of its own — every source above is either something you connect an account to, or something you supply yourself.

Questions

Frequently asked questions

Does Vespara include games?
No. Vespara does not include games or ROMs. You provide your own, legally obtained.
Does it include emulators?
No. Vespara does not bundle any emulator, BIOS file, or firmware. You install and configure each emulator yourself, then point Vespara at it.
Which versions of Windows are supported?
Windows 10 or 11, 64-bit.
Can I use my own folder structure?
Yes. Vespara does not require any particular drive letter or folder layout — you choose the Game Paths for each system in the Control Room.
Does it preserve my library during updates?
Yes. Your existing library, settings, configured paths, profiles, artwork, and play history are preserved through an update.
What are the legacy NuArcade names?
Vespara's user-facing name changed from NuArcade, but a handful of internal, technical identifiers were deliberately kept unchanged for compatibility with existing installs — the installed program is still NuArcade.exe, and configuration and library data live under a folder still named NuArcade. These names are intentional and stable across versions.
Where is the Owner's Manual?
The full Owner's Manual is kept alongside the source on GitHub: read USER_MANUAL.md.
