A world for your arcade

Your collection deserves
a home.

Vespara is a cinematic Windows arcade frontend for the emulators and games you already own. It gives your collection a place to arrive, a Library to live in, and a Control Room to shape it — instead of just another launcher window.

The journey in

Arriving somewhere, not just opening something.

Vespara doesn't drop you straight into a list of games. Every session follows the same short arrival, the same way walking up to a real cabinet would.

  1. 01

    Intro

    Vespara opens with a short cinematic intro before anything else appears.

  2. 02

    Traveler Recognition

    Pick an existing Traveler, create a new one, or continue as Guest. Each Traveler keeps their own favorites, playtime, and recently played history — a Guest's session isn't saved to anyone's profile.

  3. 03

    The Sanctuary

    You arrive in the Sanctuary — Vespara's home screen, and the place every session starts from and can return to.

Home base

The Sanctuary

From the Sanctuary, four destinations are always within reach.

The Library

Browse, search, and launch your full game collection.

The Control Room

Configure emulators, paths, controllers, display, and media.

Switch Player

Return to Traveler Recognition to hand off or switch profiles.

Depart

Close Vespara, with a confirmation step — Remain cancels and returns you to the Sanctuary, Depart closes the application.

Recently Played on the Sanctuary shows up to 8 games, scoped to whichever Traveler is currently active — a different Traveler sees their own recent games, not yours.

Where your collection lives

The Library

Games are organized by system, shown as category tabs — only systems that actually have games in them appear.

  • System-based browsing. Move between systems without losing your place.
  • Custom system logos. Replace any category's plain text with your own logo artwork.
  • Favorites. Mark games for quick access.
  • Collections. Group games into your own custom lists.
  • Search and sorting. Find a game by name, or reorder by most played, most launched, recently added, top rated, or system.
  • Archive View. Selecting a game opens its detail view — artwork, a gameplay preview video where available, and launch options.
  • Artwork and video previews. A background gameplay video plays behind the selected game where one is available.
  • AI Game Coach. Move lists, tips, strategies, and natural-language search for the selected game — no API key required.

Configuration, shaped like a place

The Control Room

Reached from the Sanctuary, the Control Room holds all of Vespara's configuration, organized into two wings.

Systems Wing

Makes the worlds playable.

  • Emulators
  • Game Paths
  • Controllers
  • Launch Behavior
  • Display & Performance
  • Preferences
  • Systems Archive

Archives Wing

Makes the collection come alive.

  • Artwork
  • Videos
  • Scraping
  • Bezels
  • Media Restoration

Opening any Archives Wing station takes you into a screen still titled Media Manager — that's the actual screen behind every Archives station, not a separate or misnamed tool.

Bringing the collection to life

Media, artwork, and video

Vespara can fill in artwork, video, and system logos around the games you already own. It does not distribute copyrighted artwork, ROMs, BIOS files, or emulator software of its own — every source below is either something you connect an account to, or something you supply yourself.

SteamGridDB artwork

Add your own API key and Vespara fetches hero art and capsule images automatically.

EmuMovies imports

Connect your own EmuMovies account and Sync app for higher-quality video and box art, then scan and import inside Vespara.

YouTube video fetching

Fetch gameplay preview video directly from YouTube, per game or in bulk.

Custom system logos

Drop your own logo images into a configured folder to replace any Library category's plain text.

Bezel support

Fills bezel gaps from your own Bezel Source Folder, RetroArch-style overlays, and Vespara's own bundled placeholder art as a last resort.

Media restoration

Backup, restore, and clean up orphaned media without losing what's already in place.

Every media feature above lives behind the Media Manager screen, reached from any Archives Wing station in the Control Room.

Questions

Frequently asked questions

Does Vespara include games?
No. Vespara does not include games or ROMs. You provide your own, legally obtained.
Does it include emulators?
No. Vespara does not bundle any emulator, BIOS file, or firmware. You install and configure each emulator yourself, then point Vespara at it.
Which versions of Windows are supported?
Windows 10 or 11, 64-bit.
Can I use my own folder structure?
Yes. Vespara does not require any particular drive letter or folder layout — you choose the Game Paths for each system in the Control Room.
Does it preserve my library during updates?
Yes. Your existing library, settings, configured paths, profiles, artwork, and play history are preserved through an update.
What are the legacy NuArcade names?
Vespara's user-facing name changed from NuArcade, but a handful of internal, technical identifiers were deliberately kept unchanged for compatibility with existing installs — the installed program is still NuArcade.exe, and configuration and library data live under a folder still named NuArcade. These names are intentional and stable across versions.
Where is the Owner's Manual?
The full Owner's Manual is kept alongside the source on GitHub: read USER_MANUAL.md.
