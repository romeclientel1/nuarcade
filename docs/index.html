What it does
Everything your cabinet needs.
🎡
HyperSpin-style wheel
Beautiful perspective wheel with real arcade artwork, smooth animations, and instant category filtering.
⚡
Auto-configuration
Point Vespara at your games folder. It finds every game, configures controllers, and sets up Windows security — automatically.
🎮
Smart controller mapping
Racing games get the wheel. Shooters get the light gun. Fighting games get the gamepad. Override per-game when needed.
🎱
Pinball included
Visual Pinball X tables live alongside your arcade games. One frontend, two worlds.
🔄
Always up to date
TeknoParrot updates silently on launch. New games appear automatically. No manual maintenance.
🎬
Video previews
Gameplay videos play on the center card. Download via built-in EmuMovies integration or drop your own .mp4 files.

Getting started
Up and running in 10 minutes.
Install TeknoParrot
Download and install TeknoParrot. Add your game files to F:/ArcadeGames/
Download Vespara
Download the Windows installer from GitHub releases and run it.
Run the wizard
The 6-screen setup wizard configures everything — security, paths, and controllers.
Play
Your full game library appears on the wheel, configured and ready to launch.
